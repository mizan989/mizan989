### Featured Work

#### 1. [NoVAult](https://github.com/mizan989/NoVAult-Password_Manager) · [Live Demo](https://novault.vercel.app)
**Zero-Knowledge Password Manager & Digital Vault**
- Built on a strict zero-knowledge architecture: sensitive payloads are encrypted client-side using **AES-256-GCM** with keys derived via **Argon2id** before ever hitting the server.
- **Stack:** React, TypeScript, Tailwind CSS, Node.js, Express, MongoDB, JWT with HTTP-only refresh rotation.

#### 2. [LooseNotion](https://github.com/mizan989/LooseNotion-Notion_Clone) · [Live Demo](https://loosenotion.vercel.app)
**Full-Stack Notion Workspace Clone**
- Collaborative productivity platform featuring a block-based **Tiptap** editor with slash commands, recursive drag-and-drop page hierarchy, and multi-view databases (Table, Board, List).
- **Stack:** Next.js 14 (App Router), TypeScript, Supabase (PostgreSQL, Auth, Row Level Security), Tailwind CSS, dnd-kit.

#### 3. [CyberSentinel](https://github.com/mizan989/CyberSentinel-Vulnerability_Scanner) · [Live Demo](https://cybersentinel-mizan.onrender.com)
**Automated Network Vulnerability Scanner & Security Reporting Dashboard**
- Security tooling engine performing automated host discovery, port scanning, service version detection (via Nmap), and offline CVE risk scoring (0–100) with PDF/HTML reporting.
- **Stack:** Python, Flask, Nmap, Docker, Nginx, Tailwind CSS.
